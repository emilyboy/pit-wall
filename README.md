# 🏎️ PITWALL – GP de São Paulo

Projeto desenvolvido como atividade prática de HTML e CSS, com o objetivo de recriar uma página inspirada no Grande Prêmio de São Paulo de Fórmula 1, realizado no Autódromo de Interlagos.

## 🎯 Objetivo

Desenvolver uma página web responsiva, utilizando apenas HTML e CSS, aplicando os conhecimentos adquiridos durante as aulas.

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- Google Fonts
- Flexbox
- CSS Grid
- Media Queries

## 🏁 Sobre o projeto

A página PITWALL apresenta informações sobre o GP de São Paulo, com um visual inspirado no universo da Fórmula 1.

O projeto contém:

- **Cabeçalho:** menu de navegação e botão para comprar ingressos.
- **Banner principal (Hero):** apresentação do GP de São Paulo e informações sobre a corrida.
- **Grid de pilotos:** cards com nomes, números e equipes dos pilotos.
- **Classificação:** tabela com posições, vitórias, diferenças e pontuação.
- **Ingressos:** informações sobre setores, preços e formulário de reserva.
- **Rodapé:** identificação da autora do projeto.

## 📱 Responsividade

O site foi desenvolvido para se adaptar a diferentes tamanhos de tela, incluindo computadores e celulares, utilizando Media Queries.
